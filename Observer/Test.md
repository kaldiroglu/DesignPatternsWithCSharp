# Tests — Observer

For further enquiry please contact Akin Kaldiroglu at akin@kaldiroglu.dev

33 xUnit tests in one project, `tests/Observer.Tests`. All of them are **unit tests**: no
process boundary, no filesystem, no network. They are a port of the JUnit tests in
`Design Patterns with Java`, package `dev.kaldiroglu.dp.behavioral.observer`: one C# test
class for each Java test class, the same test names in PascalCase, the same assertions and
the same expected values.

## What is tested

- **The price example, Part 1.** The feed that calls every screen, the screens that poll,
  and the screens that poll ten times a second: 100 reads, three of the four changes seen,
  and the alert at 105 never fires. `StageOneMain`, `StageTwoMain`, `StageThreeMain` and `FastSpikeMain` each
  print the line their slide quotes.
- **The price example, Part 3.** The `PriceFeed` with `IPriceListener`: every change is
  seen, the alert fires, a lambda can listen, a listener can leave during a notification,
  and the price is set before the listeners are told. `ListenersMain.Run()` and
  `TwoWaysMain.Run()` print the lines the slides quote.
- **GoF's clock timer.** Before and after the pattern, the same screen; the pull model; the
  timer has no field of a clock type. `Problem.Main` and `Solution.Main` print what their
  slides show.
- **The magazines and the invoice.** What each subscriber prints, and that the port's
  `Observable` tells the accountant before the boss, who was added first.
- **The .NET known uses** that the deck's table names.

Several examples print. `Printed.By` captures `Console.Out` with a `StringWriter` and
restores it in `finally`, so the project turns off xUnit's parallel run in `AssemblyInfo.cs`.

## Java tests not ported, or changed

- **`InvoiceTest.deprecatedSinceNine` is not ported.** It reads `@Deprecated(since = "9")`
  on the JDK's `java.util.Observable` and `java.util.Observer`. The port uses
  `IObservable<T>` and `IObserver<T>`, which are not deprecated.
- **`InvoiceTests` checks the .NET interfaces, not a base class.** The tests for `setChanged`
  and for `Observable` being a class have no counterpart here. `DisposeEndsTheSubscription`,
  `ASecondSubscribeIsIgnored` and `TheInterfacesAreTheOnesInSystem` take their place.
- **`KnownUsesTests` checks the .NET rows of the deck's table, not the Java rows.**
  `PropertyChangeSupport`, `Flow`/`SubmissionPublisher` and `ActionListener` are JDK types.
  The three C# tests are `INotifyPropertyChangedNamesTheProperty`,
  `ObservableCollectionTellsAddAndRemove` and `IObservableIsThePushInterface`. The C#
  `event` row is not tested here.
- **`SolutionTests.ALambdaListens` checks the interface differently.** Java checks that
  `PriceListener` carries `@FunctionalInterface` and declares one method. C# has no such
  annotation, and a C# lambda never becomes an interface. The test checks that
  `IPriceListener` is an interface that declares one method, and the lambda goes through
  the `Subscribe(Action<PriceChange>)` overload.
- **Field checks see the compiler's fields for primary constructors.** `DirectPriceFeed`
  takes its screens in a primary constructor, so its `Chart`, `Ticker` and `PriceAlert`
  fields are generated by the compiler. The reflection checks read them the same way.

No test found a difference in behavior between the C# port and the Java.

## Run it with

```bash
cd ~/"Development/NET/Design Patterns/Design Patterns with CSharp/Observer"

# all tests
~/.dotnet/dotnet test Observer.sln

# one class
~/.dotnet/dotnet test Observer.sln --filter "FullyQualifiedName~SolutionTests"

# with each test's name printed
~/.dotnet/dotnet test Observer.sln -v normal
```

`dotnet` on `PATH` cannot build this repository; `~/.dotnet/dotnet` is the .NET 10 SDK.
